# News Short Video Demo (Remotion + TypeScript)

Este projeto cria uma animação em estilo vídeo curto para redes sociais, usando React + Remotion.

Fluxo:
- notícia/relatório
- extração de texto
- IA gera roteiro
- narração mock em texto
- render de vídeo animado em 9:16
